# Session Journal (세션 작업 일지 & 문맥 보존 스킬)

> **"새 창을 열어도 맥락이 끊기지 않는다. (Context persistence without heavy databases.)"**

AI 코딩 에이전트의 가장 답답한 점은 **새 세션을 시작하면 지난번에 무엇을 결정했고 어떤 코드를 고쳤는지 전부 까먹는 '문맥 휘발(AI 치매)' 현상**입니다.  
`session-journal`은 복잡한 데이터베이스나 외부 위키 도구 없이, 프로젝트 루트의 **단 하나의 마크다운 파일(`DEV_JOURNAL.md`)**을 통해 에이전트가 영구적으로 기억을 이어받도록 만드는 초경량 기억 족쇄 스킬입니다.

---

## ⚡ 10초 적용법 (Zero-Install)

1. 이 `SKILL.md` 파일을 프로젝트 루트의 `.agents/skills/session-journal/SKILL.md`에 넣습니다.
2. AI에게 이렇게 말하세요:
   > 👉 **"지난 작업 일지 확인하고 작업 이어가줘"**  
   > 👉 **"작업 끝났으니 일지에 기록해줘"**

---

## 🛡️ 2대 자동 구속 규칙 (The 2 Core Rules)

이 스킬이 장착되면 AI는 세션의 시작과 끝에서 다음 2가지 규칙을 자동으로 따릅니다:

### 규칙 1: 세션 시작 시 (Read First)
* 새로운 작업을 시작하거나 프로젝트 분석에 착수할 때, 프로젝트 루트에 `DEV_JOURNAL.md`가 존재하는지 먼저 확인합니다.
* 파일이 있다면 **가장 최근 1~2개 세션의 기록을 먼저 읽고**, 이전 세션에서 내린 아키텍처 결정이나 주의사항을 숙지한 상태로 작업에 돌입합니다.

### 규칙 2: 작업 완료 시 (Append Record)
* 중요한 코드 수정이나 작업이 완료되면, 대화창에서만 떠들고 끝내지 않고 **반드시 `DEV_JOURNAL.md` 파일 맨 아래에 3줄 요약을 추가(Append)**합니다.
* 기존 기록을 덮어쓰거나 수정하지 않으며, 오직 시간순으로 누적 추가합니다.

## 📋 표준 기록 서식 (`DEV_JOURNAL.md`)

AI는 작업 완료 시 파일 맨 끝에 다음 표준 템플릿으로 간결하게 덧붙입니다:

```markdown
## [2026-10-24] 로그인 인증 리팩토링 및 JWT 만료 버그 해결

- **💡 핵심 결정**: 세션 기반 인증 대신 JWT 토큰 방식으로 전면 통일함. 토큰 갱신 주기를 1시간으로 단축.
- **📁 변경 파일**: `auth.py`, `middleware/jwt.ts`, `tests/test_auth.py`
- **⚠️ 주의 및 다음 할 일**: 토큰 블랙리스트 캐시는 다음 세션에서 Redis 연동 필요.
```

## 💡 왜 복잡한 위키/DB 대신 1개 파일인가?

1. **에이전트도 사람도 실제로 씁니다:**  
   수십 개의 폴더와 복잡한 옵시디언 스키마를 갖춘 무거운 위키는 AI도 깜빡하고 사람도 관리를 포기하게 됩니다. 파일 딱 1개만 관리하는 방식이 가장 오래 지속됩니다.
2. **Git 추적이 완벽합니다:**  
   `DEV_JOURNAL.md` 파일 하나만 Git에 함께 커밋되므로, 팀원이나 다른 PC에서도 `git pull`만 받으면 AI가 즉시 직전 팀원의 작업 맥락을 그대로 이어받습니다.
3. **토큰 낭비가 없습니다:**  
   수백 페이지의 위키를 뒤질 필요 없이, 파일 맨 마지막 20줄만 읽으면 되므로 컨텍스트 윈도우와 토큰 비용을 극적으로 아낄 수 있습니다.

## 🧹 [필수 관리 팁] 가끔 사람이 직접 다이어트(정리)해 주세요!

`DEV_JOURNAL.md`는 계속 누적 추가(Append-only)되는 파일이므로, 작업이 몇 주~몇 달 이상 이어지면 파일이 비대해질 수 있습니다.

* **오래된 내역 정리 (가지치기):**  
  기록이 수십 개 이상 쌓이면, 이미 몇 달 전에 완료되어 다시 볼 필요 없는 옛날 기록은 사람이 직접 삭제하거나 `DEV_JOURNAL_ARCHIVE.md`로 분리해 주세요.
* **뒤집힌 결정 정돈:**  
  도중에 기획이나 설계 방향이 완전히 뒤집혔다면, 과거의 폐기된 결정이 남아있을 때 AI가 혼선을 겪을 수 있습니다. 가끔 파일을 열어 옛날 모순된 결정을 지워주시면 AI가 항상 가장 날카로운 최신 맥락을 유지합니다.
