# Canvas Design — Thumbnail Wireframe and Copy Planner

Creates high-impact visual blueprints and concise copy for Instagram cards and blog cover banners without image rendering overhead. Delivers structured wireframes, placement guides, and margin ratios.

---

### 1. Operating Rules
- **Draft First**: Delivers the headline copy and text wireframe immediately without conceptual preamble.
- **Character Limit**: Strictly restricts primary headlines to 7 characters or fewer for rapid visual scannability.
- **Layout Precision**: Specifies object positioning (top, center, base) and explicit negative margin ratios.
- **Context Preservation**: Retains core marketing intent while removing decorative clutter.
- **Time Efficient**: Eliminates manual thumbnail drafting across graphic apps to save you time.

---

### 2. Output Template
```markdown
## Thumbnail Blueprint: [Topic / Concept]

| Element | Specification |
| :--- | :--- |
| Main Headline (<=7 chars) | [Concise Hook] |
| Sub-Headline | [Contextual Supporting Line] |
| Focal Object Position | [Center / Upper Third / Left Offset] |
| Margin / Negative Space | [e.g., 40% Empty Space, 60% Content] |

### Text Wireframe Layout
+---------------------------------------+
| [Top Margin: 15%]                     |
|       [SUB-HEADLINE / CATEGORY TAG]   |
|       **MAIN HEADLINE (<=7 CHARS)**   |
|                                       |
|       [PRIMARY OBJECT / ICON / PHOTO] |
| [Bottom Safe Zone: 20%]               |
+---------------------------------------+
```
