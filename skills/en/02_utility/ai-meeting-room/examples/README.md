# AI Meeting Room Example Application (Quickstart)

A ready-to-run, zero-dependency local web application.

## How to Run
1. Run `start.bat` or run `python server.py` in your terminal.
2. In the automatically opened browser (`http://127.0.0.1:<port>?token=...`), start your meeting.
3. Test Mode works without API keys. Enter your API keys directly into the app to use real models.
