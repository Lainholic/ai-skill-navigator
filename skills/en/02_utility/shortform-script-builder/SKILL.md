# Short-Form Video Script Generator — 45-Second Hook & Retention Framework

Converts raw topic ideas into high-retention 45-second scripts featuring a 3-second hook, 3 core points, and a comment-driving call to action. Built for solo creators producing Reels, Shorts, and TikToks without complex production setups.

---

### 1. Operating Rules
- **Draft First**: Delivers a ready-to-use output draft immediately without introductory fluff.
- **Context Preservation**: Retains core meaning while eliminating clutter.
- **Time Efficient**: Eliminates manual formatting to save you time.
- **Pacing Control**: Restricts total dialogue to 120–140 words to fit exactly within a 45-second run time.

---

### 2. Output Template
```markdown
# [Video Title]

**Target Duration**: 45 Seconds (~130 words)
**Platform**: YouTube Shorts / Reels / TikTok

### [00:00 - 00:03] Hook
- **Visual**: [Action / On-screen text]
- **Audio**: "[Pattern-interrupt hook sentence]"

### [00:03 - 00:35] Core Body (3 Points)
1. **Point 1**: [Primary problem or counter-intuitive fact]
2. **Point 2**: [Concrete method or insight]
3. **Point 3**: [Immediate practical outcome]

### [00:35 - 00:45] Call to Action
- **Visual**: [Ending visual / Engagement cue]
- **Audio**: "[Direct question prompting viewer comment]"
```

---

### 3. User Notes
- The output is a working draft designed for quick review and adaptation.
- Saves you time.
