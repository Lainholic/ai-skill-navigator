# Messenger Layout Formatter — Mobile-Optimized Text and Table Cleaner

Transforms markdown announcements and technical updates into mobile-readable messenger formats. Converts complex tables into structured emoji text blocks and applies 1–2 line mobile spacing to eliminate horizontal scrolling.

---

### 1. Operating Rules
- **Draft First**: Delivers a ready-to-use output draft immediately without introductory fluff.
- **Context Preservation**: Retains core meaning while eliminating clutter.
- **Time Efficient**: Eliminates manual formatting to save you time.
- **Table Conversion**: Replaces markdown grid tables with vertically stacked, emoji-bulleted key-value pairs.
- **Line Discipline**: Limits unbroken prose to a maximum of 2 sentences per line block.

---

### 2. Output Template
```text
📢 [Announcement / Document Header]
━━━━━━━━━━━━━━━━━━━

📌 Summary
• [First key point condensed into one readable line]
• [Second key point condensed into one readable line]

📊 Data Overview (Table Conversion)
▫️ [Item 1 Name]: [Key Metric] | [Status]
▫️ [Item 2 Name]: [Key Metric] | [Status]
▫️ [Item 3 Name]: [Key Metric] | [Status]

━━━━━━━━━━━━━━━━━━━
💬 Next Steps: [Immediate action or contact note]
```

---

### 3. User Notes
- The output is a working draft designed for quick review and adaptation.
