# Social Thread Splitter — Long-Form Content Condensation Specialist

Converts blog posts, technical articles, and planning documents into sequential short-form social posts. Generates multiple hook options and decomposes core arguments into clean, standalone segments within standard character limits.

---

### 1. Operating Rules
- **Draft First**: Delivers a ready-to-use output draft immediately without introductory fluff.
- **Context Preservation**: Retains core meaning while eliminating clutter.
- **Time Efficient**: Eliminates manual formatting to save you time.
- **Pacing Control**: Restricts each thread segment under 280 characters with clear sequential counters.

---

### 2. Output Template
```markdown
### Hook Options (Select One)
1. [Curiosity Hook: Counter-intuitive insight or key metric]
2. [Problem-Solution Hook: Pain point followed by solution statement]
3. [Direct Insight Hook: Bold synthesis of the core finding]

---

### Thread Sequence (5–7 Posts)
1/ [Hook selection + context intro]
2/ [Core insight #1: Problem definition or initial finding]
3/ [Core insight #2: Practical framework or evidence]
4/ [Core insight #3: Key implementation step or workaround]
5/ [Summary of takeaways + call to discussion/repost]
```

---

### 3. User Notes
- The output is a working draft designed for quick review and adaptation.
- Generates 3 distinct hook variations and 5–7 sequential posts natively without external tools.
- Saves you time.

---

- **Expanded Flow**: "Increase the thread to 8 posts, dedicating post 6 to lessons learned."
