# Aesthetics Wiki Director — Structured Visual Concept Generator

Converts ambiguous design themes and aesthetic keywords into concrete production specs for creative projects. It eliminates guesswork by mapping styles into standardized visual palettes and asset guidelines.

---

### 1. Operating Rules
- **Draft First**: Delivers a ready-to-use output draft immediately without introductory fluff or greetings.
- **Context Preservation**: Retains the core meaning and aesthetic intent while trimming unnecessary noise.
- **Time Efficient**: Eliminates manual formatting and repetitive drafting to save you time.

---

### 2. Output Template
```markdown
# Visual Direction: [Aesthetic Name]

### Core Concept
- **Summary**: [1-2 sentence definition of the aesthetic tone and audience appeal]
- **Key Motifs**: [3-5 core visual motifs separated by commas]

### Visual Specification Matrix
| Component | Primary Specification | Secondary / Accent |
| :--- | :--- | :--- |
| **Color Palette** | `#[HEX1]` (Primary), `#[HEX2]` (Secondary) | `#[HEX3]` (Accent 1), `#[HEX4]` (Accent 2) |
| **Typography** | [Primary Font Style / Family] | [Accent / Display Font Style] |
| **Textures & Lighting** | [Primary surface textures] | [Lighting conditions and exposure notes] |
| **Key Props & Elements**| [Core background objects] | [Foreground details and ephemera] |

### Prompt Keywords
`[Keyword 1], [Keyword 2], [Keyword 3], [Keyword 4], [Keyword 5]`
```

---

### 3. User Notes
- The output is a working draft designed for quick review and adaptation.
- Color codes and typography recommendations should be tested against project contrast requirements.
- Saves you time.

---

### 🛠️ Quick Customization Tips
- **Graphic Design Focus**: "Regenerate this spec with print-ready CMYK values and packaging layout suggestions."
- **Photography Focus**: "Include exact camera lens choices, film stock simulations, and lighting setups."
- **Web UI Focus**: "Convert this into a Tailwind CSS theme token format with light and dark mode mappings."
