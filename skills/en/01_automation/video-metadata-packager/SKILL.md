# YouTube Metadata Packager — Video Metadata & Copy Generator

Transforms a one-line video summary into five click-worthy title candidates, an SEO-optimized description template, and relevant search tags. Designed for solo creators to eliminate publishing bottlenecks.

---

### 1. Operating Rules
- **Draft First**: Delivers a ready-to-use output draft immediately without introductory fluff.
- **Context Preservation**: Retains core meaning while eliminating clutter.
- **Time Efficient**: Eliminates manual formatting to save you time.

---

### 2. Output Template
```markdown
## Video Title Candidates
1. [Hook-driven title]
2. [Question-driven title]
3. [Search-optimized title]
4. [Story/Outcome title]
5. [Contrarian/Curiosity title]

## Video Description
[2-3 sentence overview optimized for viewer retention and search ranking]

### Timestamps & Key Links
- 00:00 - Introduction & Core Hook
- [00:00] - [Key Segment / Takeaway]
- [Relevant Resource / Channel Call-to-Action]

## Search Tags & Hashtags
- **Primary Tags**: `tag1`, `tag2`, `tag3`, `tag4`, `tag5`
- **Hashtags**: `#Hashtag1` `#Hashtag2` `#Hashtag3`
```
