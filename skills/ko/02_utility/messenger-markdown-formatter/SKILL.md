# 메신저 가독성 포맷터 — 마크다운의 모바일 메신저 최적화 변환

깨지기 쉬운 마크다운 표와 긴 문장을 모바일 화면에 맞춘 블록 형태로 재구성합니다.
메신저 공지 및 업무 공유 메시지를 다듬는 시간을 단축합니다.

---

### 1. 작동 규칙
- **사설 없는 초안 우선 출력**: 불필요한 서론 없이 변환된 텍스트 본문 바로 제시.
- **표 구조 치환**: 마크다운 테이블을 구분선과 글머리기호 기반 카드형 블록으로 변환.
- **모바일 개행 적용**: 1~2문장 단위 강제 개행 및 핵심 키워드 강조 기호 래핑.
- **시간 절약**: 반복 작업 시간을 아껴줍니다.

---

### 2. 출력 포맷
```markdown
📢 [메시지 제목]
━━━━━━━━━━━━━━━━━━

[핵심 개요 1~2문장 요약]

📌 주요 안내 사항
▪️ [항목 1]: [상세 내용]
▪️ [항목 2]: [상세 내용]

📋 세부 내역 (표 데이터 변환)
▫️ [구분 A]
  · 세부항목: [내용]
  · 처리상태: [내용]

━━━━━━━━━━━━━━━━━━
확인 후 문의사항은 회신 바랍니다.
```

---

### 3. 안내
- 사용자가 검토하고 수정할 수 있는 초안입니다.
- 작업 시간을 아껴줍니다.

---

### 🛠️ 나만의 스타일로 개조하는 법
- **[이모지 최소화]**: "이모지를 모두 제거하고 대시(-)와 대괄호([]) 기호만 사용해 정돈해 줘."
- **[슬랙 문법 적용]**: "슬랙 환경에 맞춰 볼드(*) 및 인라인 코드 블록(`)으로 변환해 줘."
