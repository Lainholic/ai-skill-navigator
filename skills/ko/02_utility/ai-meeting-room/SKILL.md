# AI 회의실 제작

사용자가 AI 회의실을 만들어 달라고 요청하면 아래 요구사항에 따라 프로그램의 코드를 직접 작성하고 실행 방법을 안내한다. 사용자가 명시한 기능과 환경이 있으면 이를 우선하고, 별도 지정이 없으면 한국어 화면과 사용자의 환경에 적합한 간단한 로컬 웹 앱으로 만든다.

## 빠른 시작 (검증된 레퍼런스 예시)

사용자가 새 코드를 작성할 필요 없이 즉시 사용 가능한 회의실을 원하거나 검증된 레퍼런스를 요청하면, `examples/` 폴더에 동봉된 제로-디펜던시 로컬 웹 앱(`server.py`, `index.html`, `app.js`, `style.css`, `start.bat`)을 안내하거나 복사하여 즉시 실행할 수 있게 돕는다. 사용자가 맞춤형 UI나 별도 프레임워크를 원할 때만 아래 지침에 따라 새로 구현한다.

## 제작 범위

- 사용자가 회의 주제, 2~4명의 참여자 이름·AI 제공사·모델, 1~20회의 턴 수를 정한다. 한 턴은 각 참여자가 한 번씩 발언하는 것이다.
- 서로의 이전 발언을 다음 요청에 전달하고, 실제 제공사·모델·참여자 이름을 발언마다 표시한다. 완료된 응답이 나올 때마다 화면에 추가한다.
- 자동 진행은 매 턴 진행자 요약 후 이어진다. 직접 진행은 매 턴 사용자가 확인하고 다음 방향을 입력한 뒤 진행한다. 어떤 모델이 요약을 맡는지 표시한다.
- 사용자는 회의를 중단하고, 참여자나 요약에 오류가 났을 때 묻기·중단·계속 중에서 선택할 수 있다. 실패한 발언을 성공처럼 표시하지 않는다.
- 회의 기록을 사용자 요청으로 HTML 같은 읽기 쉬운 파일로 저장한다. 새 회의나 창 닫기 전에 저장하지 않은 기록이 사라질 수 있음을 알려준다.
- API 제공사와 모델을 선택하고, 각자의 API 키를 프로그램 입력란에 직접 넣을 수 있게 한다. 기본 후보는 OpenAI, DeepSeek, Nebius, Azure OpenAI, Vertex AI Express이며 사용자가 다른 범위를 지정하면 따른다. 공식 발급·요금 안내를 제공한다.
- API 키를 사용자 채팅이나 명령줄에 붙여 넣으라고 요구하지 않는다. 키를 소스·저장소·회의록·로그에 기록하지 않고, 사용자가 시작한 요청에만 해당 제공사로 보낸다.
- 참여자별 입력·출력 단가와 제공사의 토큰 사용량으로 비용을 추정해 표시한다. 진행자 요약도 포함하며 가격 또는 사용량을 모르는 호출과 실패·중단 요청은 미확인으로 표시한다.
- 추정액과 실제 청구액을 구분하고 캐시 할인·계약·세금 등은 다를 수 있음을 안내한다. 회의 내용이 선택한 제공사로 전달되고 API 사용료가 발생할 수 있음을 알린다.
- 키 없이 화면을 살펴볼 수 있는 테스트 모드를 제공하되 그 발언은 모의 응답이라는 사실을 화면과 저장 기록에서 명확히 표시한다.

## 구현과 검증

1. 기존 작업과 충돌하지 않는 폴더에 직접 소스 코드를 작성한다. 사용자가 요청하지 않은 배포·푸시와 기존 파일 덮어쓰기는 하지 않는다.
2. API 지원 범위와 인증 방식은 선택한 제공사의 현재 공식 문서를 확인한다. Azure 배포와 Vertex 인증처럼 제공사별 차이를 숨기거나 연결되지 않은 기능을 성공으로 표시하지 않는다. 문서나 인증을 확인할 수 없는 연결은 그 상태를 명시한다.
3. 로컬 서버는 외부 공개가 아닌 루프백에 묶고, 타 사이트의 무단 요청을 방어하며, API 키를 임의 주소·리다이렉트에 넘기지 않는다. 사용자·AI 텍스트를 실행 코드로 렌더링하지 않는다.
4. 호출 대기·실패·중단 상황에서도 이미 생성된 기록이 유지되도록 한다. 중단해도 이미 전송된 호출의 처리나 과금이 끝나지 않을 수 있음을 안내한다.
5. 실제 API 비용 없이 모의 응답으로 최소 2명·2턴을 실행해 발언 전달, 각 턴 요약, 사용자 개입, 오류 시 선택, 비용 계산과 HTML 저장을 확인한다.
6. 실제 제공자 호출이나 키 사용은 사용자가 요청한 범위에서만 한다. 확인한 기능과 미검증 제공사·플랫폼을 분리해 보고하고, 생성한 프로그램과 실행 방법을 전달한다.

스킬은 MIT 라이선스다. 새 프로그램의 라이선스는 사용자의 선택에 따르며, AI 제공사와 모델에는 해당 제공사의 별도 약관이 적용된다.
