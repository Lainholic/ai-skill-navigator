# 가챠 확률 및 성장 밸런스 설계기 — 수학적 수식 없이 정규분포 및 누적 확률 테이블 즉시 도출

복잡한 스프레드시트 수식 작성과 시뮬레이션 없이 레벨업 수치 곡선과 뽑기 확률을 빠르게 구성할 수 있도록 지원합니다. 게임 기획 초기의 밸런싱 설계 반복 작업을 줄여줍니다.

---

### 1. 작동 규칙
- **사설 없는 초안 우선 출력**: 불필요한 서론 없이 완성형 초안 바로 제시.
- **핵심 정보 보존**: 원문의 의도와 맥락 충실히 반영.

---

### 2. 출력 포맷
```markdown
## 1. 가챠 확률 및 천장 테이블
| 등급 | 기본 확률 | 천장 보정(보장 횟수) | 1회 기대 비용 |
| :--- | :--- | :--- | :--- |
| SSR | 0.0% | N회차 확정 | 000 재화 |
| SR | 0.0% | N회차 확정 | 000 재화 |
| R | 0.0% | - | 000 재화 |

## 2. 레벨업 수치 및 경험치 곡선
| 구간 | 누적 필요 경험치 | 도달 기대 플레이 타임 | 성장 계수 |
| :--- | :--- | :--- | :--- |
| Lv.1~10 | 000 | 00분 | x1.0 |
| Lv.11~30 | 0,000 | 00시간 | x1.5 |
| Lv.31~50 | 00,000 | 00시간 | x2.2 |

## 3. 밸런스 검증 요약
- 재화 소진 주기 및 목표 도달 시점 핵심 코멘트
```
