# 웹 기획서 대조 검수기 — 요구사항과 구현 결과물 간 차이 검증

작성된 화면 기획서 텍스트와 현재 개발된 화면 명세를 대조하여 누락 요소 및 변경점을 빠르게 식별합니다. 수작업 검수 시간을 아껴줍니다.

---

### 1. 작동 규칙
- **사설 없는 초안 우선 출력**: 불필요한 서론 없이 일치/불일치 대조표와 조치 권고사항을 즉시 제시합니다.
- **핵심 정보 보존**: 기획서의 명시적 기능 요구사항과 UI 텍스트 기준을 누락 없이 비교합니다.
- **시간 절약**: 버튼, 문구, 레이아웃 차이를 일목요연하게 정리해 QA 확인 시간을 아껴줍니다.

---

### 2. 출력 포맷
```markdown
# 1. 검수 결과 요약
- 총 검수 항목: 00건 | 일치: 00건 | 수정 필요: 00건

# 2. 상세 대조표
| 검수 영역 | 기획서 요구사항 | 현재 결과물 | 상태 | 조치 필요사항 |
|---|---|---|---|---|
| [UI/버튼] | [기획서 명세] | [구현 현황] | [누락/불일치/일치] | [수정 가이드] |
| [텍스트/카피] | [기획서 문구] | [노출 문구] | [누락/불일치/일치] | [수정 가이드] |
| [레이아웃] | [기획 배치 기준] | [실제 배치] | [누락/불일치/일치] | [수정 가이드] |

# 3. 우선 수정 권고사항
1. [기능 동작 필수 수정 건]
2. [단순 UI/텍스트 보완 건]
```

---

### 3. 안내
- 기획서와 구현물 간의 정합성을 확인하기 위한 1차 검수 초안입니다.
- 하나씩 눈으로 일일이 찾아 대조하는 화면 검수 작업 시간을 아껴줍니다.

---

### 🛠️ 나만의 스타일로 개조하는 법
- **[중대 결함 위주 필터링]**: "기능 오류나 버튼 누락 등 배포 블로커 이슈만 선별해 표로 정리해줘."
- **[이슈 트래커 등록용 변환]**: "지라(Jira) 티켓 양식에 맞춰 재현 경로와 기대 결과를 정리해줘."
